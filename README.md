# 日商簿記3級トレーナー

個人制作・非公式の無料学習アプリです。

- 公開ページ: https://butyukunn82.github.io/boki3-pwa2/
- このアプリについて: https://butyukunn82.github.io/boki3-pwa2/about.html
- 問題・解説の誤りや不具合: https://github.com/butyukunn82/boki3-pwa2/issues

> 本アプリは、日本商工会議所・各地商工会議所その他の試験実施団体が提供・監修・認定する公式教材ではありません。試験合格、得点、学習効果を保証するものではありません。

## 学習設計

「構造理解 → 反射化 → 本番形式」の順で、問題を見たときに何を考えればよいかを反復できるように設計しています。

主な機能:

- 第1問: 仕訳の構造理解・反復・CBT完全入力
- 第2問: 帳簿・勘定・固定資産台帳・経過勘定など
- 第3問: 決算整理後残高試算表・精算表・B/S・P/L・総合決算
- 60分の本試験型模試
- 模試の弱点分析 → 「今日の10問」への自動復習
- 習熟度・間隔反復・学習管理
- 学習データの書き出し／読み込み
- 配色・文字サイズ・アニメーション設定

## 2026年度の基準資料

2026年度向けの内容は、日本商工会議所が公表する次の資料を基準資料として参照しています。

- 2022年度適用「商工会議所簿記検定試験出題区分表」
- 2022年度適用「商業簿記標準・許容勘定科目表」
- 日本商工会議所の3級サンプル問題の出題形式・操作方法

公式情報:

- https://www.kentei.ne.jp/bookkeeping/35697-2
- https://www.kentei.ne.jp/bookkeeping/sample/sample_3

「商業簿記標準・許容勘定科目表」は出題範囲そのものではありません。個別問題で勘定科目の指定がある場合は問題文の指示が優先されます。

## 問題・採点について

問題文・数値・解説は、本アプリ用に独自作成する方針です。公式サンプルや市販教材の本文を転載することを目的としていません。

採点は学習用のアプリ内判定です。日本商工会議所の非公開の採点方法を推測して「公式採点」と表示することはありません。

許容勘定科目は `account-master.js` に候補を保持していますが、別名を常に自動正解にはせず、問題文の指定を優先できる設計にしています。

## 学習データ・プライバシー

正答履歴、習熟度、設定などの学習データは、原則として利用端末のブラウザ内（localStorage）に保存されます。本アプリ独自のアカウント登録や学習履歴用サーバーは使用していません。

GitHub Pagesへのアクセスに伴う技術情報の取扱いについては、GitHubのプライバシー方針が適用される場合があります。詳しくはアプリ内の「このアプリについて」を参照してください。

## 公開前・更新時の監査

`qa/publication-audit.mjs` を GitHub Actions で実行しています。

現在の自動監査では、少なくとも次を確認します。

- JavaScriptの構文
- Service Workerのキャッシュ対象ファイルの実在
- 模試中の強制再読み込みがないこと
- 非公式表示・免責・プライバシー表示
- 3級の主要勘定科目と許容別名の保持
- 第1問の仕訳について借方合計＝貸方合計、使用科目の存在
- 第2問の主要勘定の一致
- 第3問総合決算の貸借一致
- 過去に発見した誤答・範囲外問題の再発防止

教材追加・変更時の方針は `CONTENT_AUDIT.md` に記録しています。

## 免責

本アプリには誤りが含まれる可能性があります。受験申込み、試験制度、出題範囲、勘定科目、試験当日のルール等は、必ず日本商工会議所等の最新の公式情報を確認してください。
